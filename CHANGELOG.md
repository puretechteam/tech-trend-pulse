# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-07-29

### Added

- Initial release of Tech Trend Pulse
- Interactive trend charts with Chart.js (line and bar charts)
- Platform tabs for GitHub, npm, and PyPI data
- Search and filter functionality for technologies
- Detail panel with metrics, trend sparkline, and related technologies
- Live data fetching from public APIs with fallback to bundled static JSON
- Data caching for offline access
- Dark theme UI with CSS custom properties
